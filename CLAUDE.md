# Колесо решений

## О проекте

Одностраничный сайт «Колесо решений». Пользователь вводит варианты, крутит колесо, и оно случайно выбирает один из них.

## Технологии

- Только чистый HTML, CSS и JavaScript.
- Без фреймворков, без сборки, без npm.

## Структура

Все файлы лежат в корне репозитория:

- `index.html`
- `style.css`
- `script.js`

## Публикация

Сайт публикуется через GitHub Pages из ветки `main`.

## Интерфейс

- Весь интерфейс на русском языке.
- Сайт должен нормально выглядеть на телефоне.
